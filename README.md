# projetto_Java
Il progetto "Gestione Bacheca Annunci" è un'applicazione software che consente agli utenti di creare,  gestire, cercare e rimuovere annunci di vendita e acquisto di prodotti. Di più consente nel pulire della  bacheca. Il sistema è stato sviluppato in Java e include sia una logica backend per la gestione degli  annunci sia un'interfaccia grafica.
